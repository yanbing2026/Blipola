# Blipola

Blipola is a child-friendly AI learning buddy designed to help young learners think, try, learn, and celebrate.

## Vision

Blipola combines:
- a friendly learning companion
- an offline-first learning engine
- adaptive hints and practice
- daily learning quests
- parent insights

The first integration target is the Kindergarten Classroom project.

## Architecture

The learning engine remains authoritative. A future AI provider can generate hints, explanations, practice, and parent summaries without taking control of learning decisions.

## Status

v0.1 foundation — offline-first prototype.

## Privacy

The prototype stores learning state locally in the browser. It does not require a child email, location, or external AI account.
